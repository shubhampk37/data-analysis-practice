# IPL — Exploratory Data Analysis

An exploratory data analysis project using Indian Premier League match data from Cricsheet.

## Objective

To learn and apply the end-to-end EDA workflow on a real-world dataset:

- Understand the data
- Prepare and clean the data
- Explore distributions and patterns
- Investigate relationships
- Ask and answer analytical questions
- Interpret findings and identify their implications

## Data Source

**Cricsheet — Indian Premier League**

Cricsheet provides structured cricket data, including match information and ball-by-ball data.

Source: https://cricsheet.org/

The analysis uses Cricsheet's CSV data format.

## Current Status

**In progress.**

The initial stage focuses on understanding the structure of the IPL match data and preparing a match-level dataset for analysis.

## Notebook

`analysis.ipynb` contains the analysis and data preparation work.
